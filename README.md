# Lakehouse-Weather-Pipeline
Implement a complete automated batch ETL pipeline for your own workflow using Apache Airflow, Databricks, and AWS. Three Airflow DAGs that orchestrate REST API ingestion, historical backfills, and Athena analytics. Databricks processes raw JSON through Bronze, Silver, and Gold layers, publishing analytical Parquet data to Amazon S3 for querying with Athena.

1. Project Architecture & Implementation
A- Apache Airflow — Workflow Orchestration
B- Databricks — Data Processing
C- AWS — Storage, Cataloging & Analytics
D- Athena SQL & Analytical Queries
